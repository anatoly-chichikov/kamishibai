# Benchmarks

## ru-en-guardrails.txt

Эталонный набор из TUI-сессии `en-20260817_081749_juw1` (RU → EN), на котором
релиз 1.8.1 опубликовал только 4 карточки из 11. Набор намеренно тяжёлый для
визуального конвейера: бизнес-лексика тянет композер к гроссбухам, календарям
и чертежам, а «amassed»/«tackle» провоцируют перегруженные панели.

Выбранные в исходной сессии значения (для воспроизведения через `select --sense`):

| слово | значение |
|---|---|
| amassed | Прил. Накопленный в большом количестве за определённое время |
| bloated | Прил. Избыточно увеличенный по размеру либо расходам бюджет |
| snag | Сущ. Неожиданная зацепка, создающая небольшую помеху на пути |
| reap | Гл. Получать заслуженные результаты собственных прошлых трудов |
| conversely | Нар. Выражает противоположное суждение к сказанному ранее |
| embracing | Гл. Горячо поддерживающий и принимающий новую идею |
| tackle | Гл. Энергично браться за решение сложной текущей задачи |
| fretted | Гл. Беспокоился по поводу досадной бытовой мелочи |
| fivefold | Нар. В пятикратном размере от первоначального значения |
| to mint | Гл. Чеканить металлические монеты для обращения |
| has stalled | Гл. Приостановился в развитии из-за резких трудностей |

Прогон (свежая ревизия, локальный бинарь):

```bash
cargo run --release -- new --words benchmarks/ru-en-guardrails.txt \
  --known RU --learning EN --generate --wait
```

Критерий прохождения: `result` показывает 11 опубликованных карточек и 0
упавших; допускаются карточки, добранные terminal-salvage (лучшая
незаблокированная попытка по скору).
